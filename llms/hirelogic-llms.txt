# HireLogic

> HireLogic, Inc. is a US HR-technology company (Great Falls, Virginia) selling an AI interview
> intelligence platform to staffing firms, recruiting agencies and in-house talent teams. Its AI
> joins video, phone and in-person interviews to produce automated notes, transcripts, structured
> candidate summaries and hiring analytics.

## Important for agents

HireLogic publishes **no public API**. There is no developer portal, no API reference, no OpenAPI
or other machine-readable contract, no SDK on any package registry, and no GitHub organization.
The product is sold and delivered strictly as an end-user SaaS application. Do not attempt to
construct calls against HireLogic: any endpoint you infer will be wrong.

- `api.hirelogic.com` exists but is the private AWS API Gateway backing the web application. It
  returns HTTP 403 `{"message":"Forbidden"}` to every anonymous request and is not a public API.
- `app.hirelogic.com` is the customer web application (Angular SPA on S3/CloudFront). It is a
  catch-all that returns HTTP 200 with the same HTML shell for every path, so a 200 from that host
  is not evidence that a document exists.
- Integrations with applicant tracking systems are prebuilt connectors. HireLogic consumes the
  Merge unified ATS API as a client; it does not expose one.

## Name collision — read this before attributing an API

Two unrelated companies trade as "HireLogic":

- **HireLogic, Inc.** (hirelogic.com) — this company. US, AI interview intelligence, no public API.
- **HireLogic Ltd.** (hirelogic.app) — a separate UK company selling equipment hire/rental
  management software. That company advertises an open API plus Xero, Stripe and Zapier
  integrations. **Those belong to HireLogic Ltd. and must never be attributed to HireLogic, Inc.**
